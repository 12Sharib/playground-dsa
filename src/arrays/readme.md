# Arrays

## Easy

### Q1 - Find Largest Element

**Pattern / Algorithm**
- Array Traversal

Given an integer array `nums`, return the largest element present in the array.

Example 1:
Input: [2,5,1,3,0]
Output: 5

Example 2:
Input: [-5,-2,-10,-1]
Output: -1

### Q2 - Find Second Largest Element

**Pattern / Algorithm**
- Array Traversal
- Maintaining Two Variables

Given an integer array `nums`, return the second largest distinct element.

If no second largest element exists, return -1.

Example 1:
Input: [1,2,4,7,7,5]
Output: 5

Example 2:
Input: [5,5,5]
Output: -1

---

### Q3 - Check if Array is Sorted

**Pattern / Algorithm**
- Array Traversal

Given an integer array `nums`, determine whether the array is sorted in non-decreasing order.

Return true if sorted, otherwise false.

Example 1:
Input: [1,2,2,3,5]
Output: true

Example 2:
Input: [1,3,2]
Output: false
